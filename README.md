Mesto
Интерактивная страница, на которой можно добавлять фотографии мест, ставить лайки и просматривать информацию о карточках. Проект создан в рамках курса Яндекс Практикум.

Ссылка на GitHub Pages
Открыть проект

Технологии
HTML, CSS, JavaScript (ES6 modules)
Vite (сборщик)
REST API (Mesto API)
GitHub Actions (автодеплой)
Запуск проекта
git clone https://github.com/vadimborisov2006-cmyk/mesto-ad
npm install
npm run build
